# 帽子戏法小助手 (Hattrick Helper)

> 零后台抓包 · 零自动化代操 · 纯本地运行 · 专为 Hattrick 简体中文新手打造的游戏小助手。

## 主要功能

* **第 1–5 步新手上手向导（攻略 Tab）**：按先后顺序引导同步球队数据、选择训练方向预设（支持一键还原）、财政止血、职员配比、训练设置与 11 人首发排阵表。
* **排阵页直接贴提示**：在比赛排阵页顶部展示分步向导，并在球场 11 个位置贴出推荐球员名、在右侧名单高亮标出「🎯 拖去→位置」（点击面板「收起」后贴纸依然保留，不挡屏幕）。
* **训练 / 职员 / 青训页面伴随引导**：在训练设置页直接标出体能（10%–12%）/ 强度（100%）/ 单一主训与保存提示；在职员页标出 `4级教练 + 双4助教 + 4级队医` 省钱目标；青训页高亮 `17岁0天 + 入营112天` 提拔状态与高潜苗子。
* **今日待办体检（待办 Tab）**：大白话提醒当前最紧急事项，每张卡片附带直达目标页面按钮。
* **实用计算器与成长记录**：内置训练升星周数、青训提拔窗口、球场 `63% / 25% / 10% / 2%` 扩建计算器，以及本地 IndexedDB 跨周成长对比与 JSON 备份迁移。

## 合规与隐私说明

* **零后台抓包**：所有数据仅在你本人正常浏览 Hattrick 页面时被动读取当前页面 DOM，绝不向 `hattrick.org` 额外发请求。
* **零自动代操**：所有建议均为只读视觉提示，绝不替你自动改数值或自动点击游戏提交/购买/解雇按钮，最大程度保护账号安全。
* **纯本地存储**：球队状态与快照 100% 存储在你自己的浏览器本地（`chrome.storage.local` + `IndexedDB`），不上传任何服务器。

## 朋友怎么直接下载安装（无需安装任何开发工具）

> 推荐使用桌面端 **Chrome** 或 **Microsoft Edge**（安装后永久保留；Firefox 正式版对未签名扩展仅支持临时加载，重启浏览器会失效）。

1. 打开本仓库右侧 **Releases** 页面（或最新一次 GitHub Actions 构建产物），下载 **`hattrick-helper-chrome-mv3.zip`**。
2. 将压缩包**解压到一个长期保留、不要删除的文件夹**（例如 `D:\Extensions\hattrick-helper`）。
3. 打开浏览器扩展管理页：
   * Chrome 地址栏输入 `chrome://extensions/`
   * Edge 地址栏输入 `edge://extensions/`
4. 打开右上角的 **「开发者模式」** 开关。
5. 点击左上角 **「加载已解压的扩展程序」**，选择刚刚解压出来的文件夹（里面直接能看到 `manifest.json`）。
6. 打开任意 `hattrick.org` 页面并登录，即可在页面右下角看到 **「HT 小助手」**。

## 新手首次使用 1 分钟上手

1. 点开右下角 **「HT 小助手」**。
2. 在 **「攻略 -> 第 1 步」** 依次点一遍 `球员页 / 财政页 / 职员页 / 训练页 / 赛程页 / 青训页`，插件会自动读完你的俱乐部状态。
3. 挑选一个培养预设（选错随时可点「还原自动配置」）。
4. 切到 **「待办」** Tab 查看当前急需调整的项目，点卡片按钮直接跳去修改；排阵时点右上角 **「收起」** 即可看着球场和名单贴纸轻松拖人。
